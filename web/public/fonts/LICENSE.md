# Authentic Sans

`authentic-sans-90.woff2` and `authentic-sans-130.woff2` are Authentic Sans
by Authentic (https://authentic.website/sans), downloaded unchanged from
https://authentic.website/fonts/.

Authentic distributes Authentic Sans freely under the WTFPL for free,
open-source and educational work (https://authentic.website/license). For
commercial work it asks for a license of Authentic Sans Pro; anyone using
cisid commercially should check that page and swap the font if needed. The
UI falls back to the system font when these files are removed.
